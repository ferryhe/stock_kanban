## 二、周 2: 用户系统测试

### 2.1 用户注册功能测试

**目标**: 验证用户可以成功注册新账户

**测试步骤**:
1. 打开前端应用 → 导航到 `/register`
2. 输入用户信息:
   - Username: `testuser123`
   - Password: `TestPass123`
   - Confirm Password: `TestPass123`
3. 点击 "Create Account" 按钮
4. 预期结果: 
   - [ ] 注册成功，自动登录
   - [ ] 重定向到首页
   - [ ] 可以看到用户信息

**失败排查**:
- 如果注册失败，检查浏览器控制台的错误信息
- 验证密码至少 6 字符
- 验证用户名至少 3 字符
- 检查数据库连接

### 2.2 用户登录功能测试

**目标**: 验证用户可以登录恰当的登录流程

**测试步骤**:
1. 注册一个新用户（或使用已有用户）
2. 登出（如果已登入）
3. 导航到 `/login`
4. 输入登录信息:
   - Username: `testuser123`
   - Password: `TestPass123`
5. 点击 "Login" 按钮
6. 预期结果:
   - [ ] 登录成功
   - [ ] 重定向到首页
   - [ ] Session 建立
   - [ ] 可在 DevTools 中看到 `connect.sid` cookie

**失败排查**:
- [ ] 检查输入的用户名和密码是否正确
- [ ] 验证 express-session 中间件已加载
- [ ] 检查数据库中用户是否存在

### 2.3 用户登出功能测试

**目标**: 验证用户可以正确登出

**测试步骤**:
1. 登录一个用户账户
2. 寻找登出选项（通常在用户菜单中）
3. 点击登出
4. 预期结果:
   - [ ] Session 被清空
   - [ ] `connect.sid` cookie 被删除
   - [ ] 重定向到登录页面

### 2.4 用户资料管理测试

**目标**: 验证用户可以查询和更新资料

**测试步骤**:
1. 登录用户
2. 实现资料页面 （前端需要添加）
3. 测试获取资料:
   ```bash
   curl -H "Cookie: connect.sid=<session_id>" http://localhost:5000/api/profile
   ```
4. 预期结果:
   - [ ] 返回用户资料信息
   - [ ] 包含 displayName, riskTolerance, notifications 等字段

5. 测试更新资料:
   ```bash
   curl -X PUT -H "Cookie: connect.sid=<session_id>" \
     -H "Content-Type: application/json" \
     -d '{"displayName":"新名称","riskTolerance":"aggressive"}' \
     http://localhost:5000/api/profile
   ```
6. 预期结果:
   - [ ] 资料更新成功
   - [ ] 返回更新后的资料

### 2.5 投资组合管理测试

**目标**: 验证投资组合的 CRUD 操作

**测试步骤**:

#### 2.5.1 创建投资组合
```bash
# 创建新投资组合
curl -X POST -H "Cookie: connect.sid=<session_id>" \
  -H "Content-Type: application/json" \
  -d '{
    "name":"AI Stock Strategy",
    "initialCash":100000,
    "type":"live"
  }' \
  http://localhost:5000/api/portfolios
```

预期结果:
- [ ] 返回状态 201
- [ ] 返回创建的投资组合 ID
- [ ] 投资组合名称、初始资金正确

#### 2.5.2 查询投资组合列表
```bash
curl -H "Cookie: connect.sid=<session_id>" \
  http://localhost:5000/api/portfolios
```

预期结果:
- [ ] 返回当前用户的所有投资组合
- [ ] 排除其他用户的投资组合（权限隔离）
- [ ] 包含投资组合的关键信息

#### 2.5.3 查询投资组合详情
```bash
curl -H "Cookie: connect.sid=<session_id>" \
  http://localhost:5000/api/portfolios/<portfolio_id>
```

预期结果:
- [ ] 返回投资组合详细信息
- [ ] 包含初始资金、当前资金、总价值
- [ ] 包含持仓列表
- [ ] 包含最近交易（最多 20 条）
- [ ] 包含最新的结算数据

## 四、数据隔离与权限测试

### 4.1 用户隔离测试

**目标**: 验证用户只能访问自己的数据

**测试步骤**:
1. 创建用户 A 并登登录，创建投资组合 PA
2. 创建用户 B 并登登录
3. 用户 B 尝试访问用户 A 的投资组合 PA:
   ```bash
   curl -H "Cookie: connect.sid=<B_session>" \
     http://localhost:5000/api/portfolios/<PA_id>
   ```
4. 预期结果:
   - [ ] 返回 404 Not Found
   - [ ] 不暴露用户 A 的数据

### 4.2 会话隔离测试

**目标**: 验证会话正确隔离

**测试步骤**:
1. 打开两个浏览器窗口
2. 分别登录用户 A 和用户 B
3. 验证每个会话的独立性:
   - [ ] 用户 A 的会话仅看到用户 A 的数据
   - [ ] 用户 B 的会话仅看到用户 B 的数据
   - [ ] 登出一个用户不影响另一个用户
